# 트립첵! Trip-Check

가족이 함께 쓰는 여행 준비물 체크리스트와 여행 기록입니다. 캠핑 체크리스트 캠첵!(Cam-Check)의 자매 앱입니다.

- 주소: https://musicalpe.github.io/Trip-Check/
- 구글로 로그인해 가족 공간을 만들고, 가족 초대 QR로 함께 씁니다.
- 체크는 실시간으로 함께 보이고, 인터넷이 끊겨도 기기에 두었다가 연결되면 올라갑니다.

## 할 수 있는 것

- 구역별 준비물 체크, 챙긴 것 숨기기, 체크 모두 지우기, 구역 접기
- 꼭 챙길 물건 강조(꼭! 표시)
- 연필로 항목·구역 이름 고치기, 휴지통으로 빼기, 손잡이를 끌어서 순서 바꾸기(다른 구역으로도)
- 상황 설정: 해외·비행기·아이와 함께·물놀이·추울 때처럼 상황을 만들고 버튼으로 켜고 끄기
- 여행 기록: 출발일·박·여행지·교통편·메모·우리 별점, 챙긴/안 챙긴 항목, 우리 여행지 순위
- 앱으로 설치(홈 화면 아이콘)
- 계정·자료 관리: 여행 기록 내려받기(CSV), 가족 공간에서 나가기, 계정과 자료 모두 지우기
- 개인정보처리방침: `privacy.html`

## 파이어베이스

캠첵!과 따로 쓰는 파이어베이스 프로젝트(trip--check)를 씁니다. 자료는 `tripFamilies`, `tripUsers` 에 둡니다. 보안 규칙은 `보안규칙.txt`.
