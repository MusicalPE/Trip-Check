올리기 전 시험

  bash tests/run.sh check   단순 수정(글귀, 색, 여백, 그림 교체) — 코드 검사만
  bash tests/run.sh full    기능 수정(새 기능, 화면 배치, 서버·저장 방식) 또는 애매할 때 — 전체 시험

코드 검사: 자바스크립트 문법(따옴표·괄호 짝), HTML 태그·CSS 중괄호 짝,
           코드가 찾는 id와 단추가 부르는 함수가 실제로 있는지,
           판 번호(index.html APP_VER, sw.js 캐시 이름)가 같은지
전체 시험: 코드 검사 + 화면을 실제로 띄워 체크·꼭!·접기·상황·출발/철수·되돌리기·날씨·식단(일정)·
           기록·세팅 공유·가족 공간 주고받기·고치기·순서 편집·출력·의견 보내기 등을 한 번씩 밟아 봄

하나라도 실패하면 올리지 말고 먼저 고칩니다.
판을 올릴 때는 index.html 의 APP_VER 와 sw.js 의 CACHE 를 같은 번호로 바꿉니다.
